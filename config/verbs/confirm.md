---
id: confirm
label: CONFIRM
key: enter
requires: blocked
---
Answers a permission prompt by accepting the highlighted option, so an agent
waiting on approval can carry on without you leaving the deck to type.

Valid only against a blocked agent -- one that is genuinely asking. Against a
working or idle agent it refuses, so a press can never send a stray return into
a prompt box or submit an empty turn.

It accepts whatever the dialog has selected, which is the narrow option: this
call only, not a standing permission. That is deliberate. A key that granted a
class of action for the rest of the session would be a much larger decision
than one press should carry, and the deck cannot show you what you would be
agreeing to.

Which means the one thing this key cannot do is read the dialog for you. It
approves what is on the screen; you still have to have looked.
